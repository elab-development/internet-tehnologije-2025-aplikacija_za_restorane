# Aplikacija za rezervaciju restorana

Ova aplikacija omogućava korisnicima da pregledaju restorane i naprave rezervaciju stola.  
Menadžeri restorana mogu da upravljaju restoranima, stolovima i zahtevima za rezervaciju.

## Tehnologije

- Next.js
- React
- TypeScript
- Prisma ORM
- MySQL

## Funkcionalnosti

- pregled restorana
- prikaz lokacija restorana na mapi
- rezervacija stola
- pregled sopstvenih rezervacija
- izmena i otkazivanje rezervacija
- prijava i registracija korisnika
- opcija za zaboravljenu lozinku
- menadžerski panel za upravljanje stolovima
- odobravanje i odbijanje zahteva za rezervaciju

## Pokretanje aplikacije

1. Klonirati repozitorijum

git clone https://github.com/elab-development/internet-tehnologije-2025-aplikacija_za_restorane.git

2. Uci u folder projekta

cd internet-tehnologije-2025-aplikacija_za_restorane

3. Instalirati zavisnosti

npm install

4. Pokrenuti aplikaciju

npm run dev

5. Aplikacija će biti dostupna na adresi

http://localhost:3000

## Napomena

Za pravilno funkcionisanje aplikacije potrebno je da baza podataka bude pokrenuta i da je pravilno podesen `.env` fajl.
